# Purr 🐾

> Легковесный, современный модальный терминальный текстовый редактор на Си (<2500 строк) со встроенным LSP, гибридным автодополнением по Tab, статическим анализом, подсветкой синтаксиса и расширяемостью через LuaJIT — готовый к работе сразу «из коробки» без конфигураций.

[English](README.md) | [Русский](README_RU.md) | [Плагины на Lua](docs/PLUGINS_RU.md)

---

## 🎯 Почему Purr?

Современный мир редакторов впал в крайности:
- **Сборки Neovim** (`LazyVim`, `LunarVim`, `AstroNvim`) требуют сотен хрупких плагинов, сложных пакетных менеджеров (`lazy.nvim`, `mason.nvim`) и гигабайтов зависимостей, которые ломаются при очередном обновлении.
- **Micro и Nano** просты, но не имеют встроенного понимания кода, LSP, семантического автокомплита и диагностики компилятора в реальном времени.

**Purr объединяет лучшее из двух миров.** Он даёт функционал полноценной IDE в мгновенно запускающемся, монолитном терминальном бинарнике без необходимости настраивать что-либо вручную.

### Ключевые возможности

* **LSP «из коробки» без плагинов**: Автоматическое обнаружение установленных серверов для ~30 языков программирования (`clangd`, `pyright`, `rust-analyzer`, `gopls`, `zls` и др.).
* **Компактность и скорость**: Менее **2500 строк** чистого модульного Си99 и бинарник размером всего **~55 КБ**. Запуск происходит быстрее 2 миллисекунд.
* **Неблокирующий асинхронный I/O**: Общение с языковыми серверами и анализаторами работает через неблокирующие пайпы (`poll`) без зависания интерфейса терминала.
* **Эргономичная навигация на домашнем ряде (`jkl;`)**:
  - Устаревший `hjkl` (созданный в 1970-х для терминалов Lear Siegler) заменён на естественный **`jkl;`** (`j`: влево, `k`: вниз, `l`: вверх, `;`: вправо). Пальцы лежат прямо на домашнем ряде без неестественного сдвига кисти влево.
  - Вход в режим вставки — клавиша **`a`** прямо в позиции курсора.
  - Универсальные шорткаты спасения: `Ctrl+S` (сохранить), `Ctrl+Q` (выйти), `Ctrl+C` (возврат в Normal Mode).
* **Гибридный автокомплит по Tab**:
  - Семантические подсказки от активного LSP-сервера.
  - Мгновенный автоматический фоллбек: поиск слов в текущем буфере + ключевые слова языка, если LSP не установлен или ещё запускается.
  - Листание вариантов по `Tab` или `↓`/`Ctrl+N`, назад по `↑`/`Ctrl+P`, выбор по `Enter`.
* **Встроенный статический анализ**: Поддержка `clang-tidy`, `cppcheck`, `shellcheck` и `ruff` прямо при сохранении или по команде `:check`.
* **Nerd Fonts из коробки**: Бейдж котика (`󰄛`) в статусной строке, иконки типов файлов (``, ``, ``), маркеры ошибок в гаттере (`󰅚` ошибка, `󰀪` предупреждение, `󰋽` инфо).
* **Умные авто-скобки и отступы**:
  - Автозакрытие пар: `()`, `[]`, `{}`, `""`, `''`.
  - Умный перескок через закрывающую скобку без дублирования.
  - Удаление обеих скобок по Backspace между пустой парой.
  - Умный отступ на `Enter` и автоматический сдвиг влево при вводе `}`.
* **Полноценная поддержка UTF-8 и русского языка**: Честная работа с многобайтным UTF-8. Курсор не прыгает, русский текст вводится и редактируется идеально.
* **Расширяемость через LuaJIT**: Встроенный LuaJIT 2.1 позволяет писать собственные команды, авто-форматтеры и интеграции с околонативной скоростью ([Руководство по плагинам на Lua](docs/PLUGINS_RU.md)).

## 🚀 Быстрый старт

### Требования
- Компилятор Си (`gcc` или `clang`)
- `make`
- `luajit` (`libluajit-5.1-dev` в Debian/Ubuntu, `luajit` в Arch Linux)
- Библиотека `tree-sitter`
- Терминал с поддержкой шрифтов [Nerd Fonts](https://www.nerdfonts.com/) (например, JetBrains Mono Nerd Font, FiraCode Nerd Font, Alacritty, Kitty, WezTerm).

### Сборка и установка

```bash
# Клонирование репозитория
git clone https://github.com/Fred-Lght/purr.git
cd purr

# Сборка (занимает меньше 2 секунд)
make

# Вариант А: Общесистемная установка в корень (в /usr/local/bin, доступно везде)
sudo make install

# Вариант Б: Установка только для своего пользователя (в ~/.local/bin, без root/sudo)
make install PREFIX=$HOME/.local

# Запуск редактора из любой папки системы!
purr [имя_файла]
```

## ⌨️ Горячие клавиши

### Универсальные (работают в ЛЮБЫХ режимах)
| Сочетание | Действие |
| :--- | :--- |
| `Ctrl + S` | Моментальное сохранение файла |
| `Ctrl + Q` | Безопасный выход (предупредит при несохраненных изменениях) |
| `Ctrl + C` / `Esc` | Возврат в **Normal Mode** / Закрыть меню автокомплита |

### Normal Mode (Командный режим по умолчанию)
| Клавиша | Действие |
| :--- | :--- |
| **`j`** | Курсор **влево** (указательный палец) |
| **`k`** | Курсор **вниз** (средний палец) |
| **`l`** | Курсор **вверх** (безымянный палец) |
| **`;`** | Курсор **вправо** (мизинец) |
| **`a`** | Вход в **Insert Mode** прямо на курсоре |
| `w` / `b` | На слово вперед / назад |
| `0` / `$` | В начало / в конец строки |
| `g` / `G` | В начало / в самый конец файла |
| `o` / `O` | Новая строка снизу / сверху с переходом в Insert Mode |
| `x` | Удалить символ под курсором |
| `d d` | Удалить текущую строку целиком |
| `K` | LSP Hover (документация и типы символа под курсором) |
| `:` | Открыть командную строку редактора |

### Insert Mode (Режим вставки текста)
| Клавиша | Действие |
| :--- | :--- |
| `Tab` | Открыть автодополнение / листать варианты вперед |
| `↓` / `Ctrl + N` | Выбрать следующий вариант дополнения |
| `↑` / `Ctrl + P` | Выбрать предыдущий вариант дополнения |
| `Enter` | Подтвердить и вставить выбранный вариант / перенос строки с отступом |
| `Backspace` | Удалить символ (удаляет пару скобок, если курсор внутри `()`) |
| `Esc` / `Ctrl + C` | Закрыть меню подсказок или выйти в Normal Mode |

### Command Mode (`:`)
| Команда | Действие |
| :--- | :--- |
| `:w [имя]` | Сохранить файл |
| `:q` | Выйти из редактора |
| `:q!` | Принудительно выйти без сохранения |
| `:wq` | Сохранить и выйти |
| `:e <путь>` | Открыть файл в буфере |
| `:check` | Запустить статический анализ (`clang-tidy`, `ruff`, etc.) |
| `:lsp start` | Запустить сервер LSP для текущего файла |
| `:lsp status` | Показать текущий статус LSP |
| `:lsp hover` | Документация символа (аналог клавиши `K`) |
| `:lsp def` | Перейти к определению символа (Go To Definition) |
| `:lsp list` | Показать список поддерживаемых серверов |
| `:lsp set <язык> <команда>` | На лету зарегистрировать или переопределить сервер |
| `:lua <код>` | Выполнить код Lua прямо в редакторе |
| `:help` | Краткая справка по клавишам в статусной строке |

## 🔌 Поддерживаемые языки и LSP

Purr автоматически находит и подключает серверы из вашего `$PATH`:

| Язык | Основной сервер | Альтернативы / Фоллбек | Анализаторы и линтеры |
| :--- | :--- | :--- | :--- |
| **C / C++** | `clangd` | `ccls` | `clang-tidy`, `cppcheck` |
| **Python** | `pyright` | `pyright-langserver`, `pylsp`, `ruff` | `ruff`, `flake8` |
| **Rust** | `rust-analyzer` | — | `clippy` |
| **Go** | `gopls` | — | `golangci-lint` |
| **TypeScript / JS**| `typescript-language-server` | `vtsls`, `deno` | `eslint` |
| **Lua** | `lua-language-server` | — | `luacheck` |
| **HTML / CSS / JSON**| `vscode-html-language-server` | `vscode-css-language-server` | — |
| **Shell** | `bash-language-server` | — | `shellcheck` |
| **Zig** | `zls` | — | — |
| **PHP** | `intelephense` | `phpactor` | `phpstan` |

Установка LSP в Arch Linux:
```bash
sudo pacman -S clang          # C/C++ (clangd)
sudo pacman -S pyright        # Python
sudo pacman -S rust-analyzer  # Rust
sudo pacman -S gopls          # Go
```

## 🧩 Разработка плагинов на Lua

Purr содержит встроенный LuaJIT 2.1. Добавлять свои команды, авто-форматтеры и плагины можно прямо в `runtime/init.lua`.

Подробное описание функций API и примеры кода доступны в [Руководстве по плагинам](docs/PLUGINS_RU.md).
