# Purr 🐾

> Легковесный, модальный терминальный текстовый редактор на Си с встроенным LSP, подсветкой синтаксиса и расширяемостью через Lua — готовый к работе сразу «из коробки».

---

## 🎯 Философия Purr

В отличие от современных дистрибутивов Neovim, требующих установки сотен плагинов (`lazy`, `mason`, `nvim-lspconfig`, `cmp`), которые регулярно ломаются при обновлениях:

* **Готов к работе сразу**: LSP и подсветка синтаксиса встроены и включаются автоматически при открытии файла (например, `clangd` для C/C++, `pyright` для Python).
* **Компактная кодовая база**: всего **~1870 строк** чистого, модульного Си и **51 КБ** бинарник!
* **Асинхронный I/O без раздувания**: JSON-RPC протокол языковых серверов работает в неблокирующем цикле (`poll`) через pipes, не подвешивая терминал и не требуя многопоточного ада.
* **Эргономичный модал на домашнем ряде**:
  - Устаревший `hjkl` заменён на естественный **`jkl;`** (пальцы лежат прямо на домашнем ряде клавиатуры, без смещения руки влево).
  - Вход в режим вставки осуществляется по клавише **`a`** прямо в позиции курсора.
  - Универсальные шорткаты спасения: `Ctrl+S` (сохранить) и `Ctrl+Q` (выйти).
* **Универсальный LSP**: Реестр с авто-обнаружением серверов для десятков языков, автоматическое определение корня проекта (`.git`, `Cargo.toml`, `package.json`, `Makefile` и др.), быстрый показ документации по `K` и переход к определению через `:lsp def`.
* **LuaJIT расширяемость**: полноценное API для написания пользовательских плагинов, команд и хуков на Lua.

## 🚀 Быстрый старт

### Сборка и запуск

```bash
# Сборка (требуются luajit, tree-sitter, gcc/clang)
make

# Запуск редактора
./purr [путь_к_файлу]
```

## ⌨️ Управление (Горячие клавиши)

### Универсальные (работают в любых режимах)
- `Ctrl + S`: Моментальное сохранение буфера.
- `Ctrl + Q`: Безопасный выход из редактора (предупреждает о несохраненных изменениях).

### Normal Mode (Командный режим по умолчанию)
- `j`: Курсор **влево** (указательный палец)
- `k`: Курсор **вниз** (средний палец)
- `l`: Курсор **вверх** (безымянный палец)
- `;`: Курсор **вправо** (мизинец)
- `a`: Переход в **Insert Mode** (режим вставки) прямо на позиции курсора.
- `w` / `b`: Переход на слово вперед / назад.
- `0` / `$`: В начало / в конец строки.
- `g` / `G`: В начало / в самый конец файла.
- `o` / `O`: Вставить новую строку снизу / сверху и перейти в режим вставки.
- `x`: Удалить символ под курсором.
- `d d`: Удалить текущую строку.
- `K`: Показать документацию/тип символа под курсором (LSP Hover).
- `:`: Открыть командную строку редактора.

### Insert Mode (Режим вставки текста)
- Обычный ввод текста и символов.
- `Enter`: Новая строка.
- `Backspace` / `Delete`: Удаление символов.
- `Esc`: Возврат в Normal Mode.

### Command Mode (Командная строка `:`)
- `:w [имя_файла]` — Сохранить файл.
- `:q` — Выйти (с проверкой изменений).
- `:q!` — Принудительно выйти без сохранения.
- `:wq` — Сохранить и выйти.
- `:e <файл>` — Открыть файл в текущем буфере.
- `:lsp [start|status|hover|def|stop|list|set <lang> <cmd>]` — Управление LSP.
  - `:lsp list` — список поддерживаемых языков.
  - `:lsp hover` или клавиша `K` — документация к символу под курсором.
  - `:lsp def` — переход к определению (Go To Definition).
  - `:lsp set <язык> <команда>` — привязать любой кастомный сервер на лету!
- `:lua <код>` — Выполнить произвольный Lua-код прямо в редакторе!
- `:help` — Вывести краткую справку по горячим клавишам.

## 🔌 Архитектура универсального LSP

Purr автоматически ищет установленные в системе серверы по приоритету:

| Язык | Поддерживаемые серверы (авто-выбор первого доступного) |
| :--- | :--- |
| **C / C++** | `clangd`, `ccls` |
| **Python** | `pyright-langserver`, `pylsp`, `basedpyright`, `ruff` |
| **Rust** | `rust-analyzer` |
| **Go** | `gopls` |
| **TypeScript / JS** | `typescript-language-server`, `vtsls`, `deno` |
| **Zig** | `zls` |
| **Bash / Shell** | `bash-language-server` |
| **Lua** | `lua-language-server` |
| **HTML / CSS / JSON**| `vscode-html-language-server`, `vscode-css-language-server`, `vscode-json-language-server` |
| **C#** | `csharp-ls`, `OmniSharp` |
| **Java** | `jdtls` |
| **PHP** | `intelephense`, `phpactor` |
| **Ruby** | `solargraph`, `ruby-lsp` |
| **Kotlin** | `kotlin-language-server` |
| **Dart** | `dart language-server` |
| **Markdown** | `marksman` |
| **YAML** | `yaml-language-server` |
| **CMake** | `cmake-language-server`, `neocmakelsp` |

Если у вас редкий или новый язык, достаточно одной команды:
```vim
:lsp set v v-analyzer
```
или в Lua:
```lua
purr.lsp.register("v", { cmd = "v-analyzer", args = {} })
```
