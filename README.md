# Purr 🐾

> Легковесный, модальный терминальный текстовый редактор на Си с встроенным LSP, подсветкой синтаксиса и расширяемостью через Lua — готовый к работе сразу «из коробки».

---

## 🎯 Философия Purr

В отличие от современных дистрибутивов Neovim, требующих установки сотен плагинов (`lazy`, `mason`, `nvim-lspconfig`, `cmp`), которые регулярно ломаются при обновлениях:

* **Готов к работе сразу**: LSP и подсветка синтаксиса встроены и включаются автоматически при открытии файла (например, `clangd` для C/C++, `pyright` для Python).
* **Компактная кодовая база**: всего **~1850 строк** чистого, модульного Си и **51 КБ** бинарник!
* **Асинхронный I/O без раздувания**: JSON-RPC протокол языковых серверов работает в неблокирующем цикле (`poll`) через pipes, не подвешивая терминал и не требуя многопоточного ада.
* **Гибридное модальное управление**: привычные модальные команды Vim (`h/j/k/l`, `i`, `a`, `o`, `dd`, `x`, `:`) объединены с универсальными шорткатами спасения (`Ctrl+S` — сохранить в любом режиме, `Ctrl+Q` — безопасный выход).
* **LuaJIT расширяемость**: полноценное API для написания пользовательских плагинов, команд и хуков на Lua.

## 🚀 Быстрый старт

### Сборка и запуск

```bash
# Сборка (требуются luajit, tree-sitter, gcc/clang)
make

# Запуск редактора
./purr [путь_к_файлу]
```

## ⌨️ Управление (Горячие клавиши)

### Универсальные (работают в любых режимах)
- `Ctrl + S`: Моментальное сохранение буфера.
- `Ctrl + Q`: Безопасный выход из редактора (предупреждает о несохраненных изменениях).

### Normal Mode (Командный режим по умолчанию)
- `h`, `j`, `k`, `l` или стрелки: Перемещение курсора (влево, вниз, вверх, вправо).
- `w` / `b`: Переход на слово вперед / назад.
- `0` / `$`: В начало / в конец строки.
- `g` / `G`: В начало / в самый конец файла.
- `i`: Переход в режим вставки перед курсором.
- `a`: Переход в режим вставки после курсора.
- `o` / `O`: Вставить новую строку снизу / сверху и перейти в режим вставки.
- `x`: Удалить символ под курсором.
- `d d`: Удалить текущую строку.
- `:`: Открыть командную строку редактора.

### Insert Mode (Режим вставки текста)
- Обычный ввод текста и символов.
- `Enter`: Новая строка.
- `Backspace` / `Delete`: Удаление символов.
- `Esc`: Возврат в Normal Mode.

### Command Mode (Командная строка `:`)
- `:w [имя_файла]` — Сохранить файл.
- `:q` — Выйти (с проверкой изменений).
- `:q!` — Принудительно выйти без сохранения.
- `:wq` — Сохранить и выйти.
- `:e <файл>` — Открыть файл в текущем буфере.
- `:lsp [start|status|stop]` — Управление языковым сервером.
- `:lua <код>` — Выполнить произвольный Lua-код прямо в редакторе!
- `:help` — Вывести краткую справку по горячим клавишам.

## 🔌 Архитектура LSP «из коробки»

Purr не требует внешних пакетных менеджеров для работы с языковыми серверами.
При открытии файла редактор определяет его тип и автоматически инициирует асинхронный запуск соответствующего сервера через stdin/stdout каналы:

| Язык | Сервер | Описание |
| :--- | :--- | :--- |
| **C / C++** | `clangd` | Быстрый синтаксический анализ, диагностика, автодополнение |
| **Python** | `pyright` / `pylsp` | Анализ типов и ошибки |
| **Rust** | `rust-analyzer` | Диагностика кода на Rust |
| **Go** | `gopls` | Официальный LSP сервер Go |
| **Lua** | `lua-language-server` | Диагностика скриптов Lua |

Диагностические сообщения (ошибки, предупреждения) выводятся прямо в статусной строке редактора в реальном времени.

## 🛠️ Структура проекта

```
purr/
├── Makefile            # Минималистичный Makefile с автоматическим pkg-config
├── README.md           # Документация
├── src/
│   ├── main.c          # Точка входа, главный цикл событий poll()
│   ├── terminal.c/.h   # Терминальный raw-mode драйвер (ANSI/VT100, TrueColor)
│   ├── buffer.c/.h     # Текстовый буфер строк, операции вставки/удаления, I/O
│   ├── editor.c/.h     # Режимы (Normal/Insert/Command), статус-бар, курсор
│   ├── syntax.c/.h     # Быстрая подсветка синтаксиса с палитрой Dracula
│   ├── async_io.c/.h   # Неблокирующие каналы (pipes) для фоновых LSP процессов
│   └── lua_bridge.c/.h # Встраиваемый LuaJIT, экспорт C API в Lua
└── runtime/
    ├── init.lua        # Стандартные команды и хуки жизненного цикла
    ├── json.lua        # Встроенный JSON-парсер/сериализатор
    └── lsp.lua         # Встроенный LSP клиент протокола JSON-RPC
```
